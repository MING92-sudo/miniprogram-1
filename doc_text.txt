重庆市智慧特种设备安全管理系统
电梯维保记录上报接口规范

一、平台接口定义
1.1接口基本要求
接口类别
通过统一Restful接口提供服务
接口协议
接口通信协议采用HTTPS协议
请求类型
统一采用POST请求类型
请求数据格式
请求数据以及响应数据采用JSON格式

1.2接口返回，统一数据格式
参数名
必选
类型范围
说明
code
是
String
接口调用返回码。
200：请求响应成功
…
message
否
String
成功提示或者错误提示信息
data
否
String
业务响应数据

二、接口详情
2.1登录获取token
接口调用前需要调用认证服务获取token，根据token调用具体的业务接口。
服务说明
根据用户名等信息，获取认证信息
请求方式
POST
URL地址
https://{AUTH_ROOT}/login
参数列表
输入参数
参数说明

username
由重庆市智慧特种设备安全管理系统分配，必填

key
由重庆市智慧特种设备安全管理系统分配，必填

appcode
由重庆市智慧特种设备安全管理系统分配，必填

secret
由重庆市智慧特种设备安全管理系统分配，必填
返回值示例
{
  "code": 200，
  "message": "操作成功"，
  "data": {
    "access_token": "e ",//token
    "expires_in": 3599 // 有效期时长，单位秒
  }
}

2.3维保服务关系维护
服务说明

参数列表
输入参数
参数说明

useUnit

useUnitEntityID
使用单位ID(必填)

changState

}

2.7 查询电梯基本信息
服务说明
通过电梯出厂编号、电梯编码、电梯注册代码查询电梯基本信息，至少输入一个查询条件。
请求方式
POST
URL地址
http://{API_ROOT}/equipment/queryElevatorInfo
Header
Authorization: Bearer TOKEN
参数列表
输入参数
参数说明

factoryNumber
电梯出厂编号（选填）

registrationCode
电梯注册代码（选填）

deviceCode
电梯设备代码（选填）
返回值
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "elevatorCode": "130421",//电梯编码            "useUnitEntityId": "5633318206815862786",//电梯使用单位主体ID            "elevatorAdminister": "鄢鱼",//使用单位安全管理员            "registrationCode": "31305001122014017242",//电梯注册代码            "deviceCode": "31305001122014017242",//电梯设备代码            "elevatorAdministerPhone": "1582****892",//使用单位安全管理员手机            "emergencyPhone": "400****588",//紧急联系电话            "factoryNumber": "SGL20131212-1"//出厂编号
    }
  ]
}

2.8 电梯维保记录提交
服务说明
本接口不临时接口，仅用于维保单位提交已有存量电梯维记录，后续将适时关闭。关闭后请使用2.6上传后续产生的维保记录。
请求方式
POST
URL地址
http://{API_ROOT}/record/uploadMaintainRecord
Header
Authorization: Bearer TOKEN
参数列表
输入参数
参数说明

elevatorCode
电梯编码（必填）

workType
维保类型（详见3.1）（必填）

startTime
维保开始时间（格式为yyyy-MM-dd hh24:mi:ss）（必填）

endTime
维保结束时间（格式为yyyy-MM-dd hh24:mi:ss）（必填）

workManName1
维保人员姓名1（必填）

workManName2
维保人员姓名2（必填）

originalRecordId
原始维保记录ID（必填）

recorder
维保记录填写人（必填）

recorderPhone
维保记录填写人手机（必填）
返回值
{
  "code": 200,
  "message": "操作成功",
  "data": null
}

3.2严重事故隐患码表
代码
含义
S0
未发现严重事故隐患
S1
使用非法生产的特种设备
S2
超过特种设备的规定参数范围使用
S3
缺少安全附件、安全装置，或者安全附件、安全装置失灵而继续使用
S3
使用应当予以报废或者经检验判定为不合格的特种设备
S5
使用有明显故障、异常情况的特种设备，或者使用经责令改正而未予以改正的特种设备
S6
特种设备发生事故不予报告而继续使用
S7
其它严重事故隐患
