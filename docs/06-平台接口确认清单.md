```json
{"code":404,"message":"404 NOT_FOUND","data":null}
```

- ❌ **token 无效**：无 token 返回 **401**，带 token 变 **404** → **token 已被接受，鉴权已通过**

- ⚠️ **我方推测**：结合 DNS 记录被摘除、根路径显示 nginx 默认页、`/api` 301 跳转至**未开放的 1444 端口**，判断平台**可能正在重新部署/调整网关，业务路由尚未注册完成**。
