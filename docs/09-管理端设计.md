# 一、目标与范围

## 1.1 定位

管理端（最小后台）服务维保部管理员（班组长只读），承担**档案维护、计划调度、工单监控、上报异常闭环、平台同步、密码重置**六项必要管理，并为全部监管平台交互（2.1—2.8）提供管理入口。后端已就绪的能力直接复用，管理端不重复造轮子。

## 1.2 本期范围（V2.0 裁剪后，docs/01 §10.3 同步）

1. **档案管理**：维保单位、使用单位、人员、电梯四类档案查看与维护（含手机号互斥预校验 1002、**2.2 主体ID同步**、2.7 平台回填、维保人员分配、**批量绑定维保人员**、**人员重置密码**、**电梯删除/停用/二维码/批量经纬度**；合同仅起止日期字段）。
2. **计划调度**：排班看板、指派、转派、延期审批；**自动派单（每日 09:00 到期扫描 + 类型自动升级 + 触达补派）+ 首次维保/补单手动派单（电梯"立即派单"）**。
3. **工单监控**：工单列表筛选与详情（只读复用小程序契约）。
4. **上报异常闭环**：`reportStatus=FAILED` 记录清单 + 手动重报（2.6）；上报日志查询（脱敏展示）；**维保记录管理端预览 + PDF 下载**（复用 A.0.3 内容：基本信息/检查项明细/照片/三方签字）。
5. **平台同步看板**：2.5 人员同步、2.7 电梯回填、最近同步时间、**2.1 凭证状态** + 手动触发同步。
6. **平台登记（2.3/2.4 独立页）**：维保服务关系维护（建立/终止）、维保人员登记（建立/终止），multipart 合同/证书文件必填。

**V2.0 裁剪（不再交付）**：合规台账、统计报表、预警规则配置、订阅消息管理、用户权限管理、日志审计、定位异常申述审核、检查项模板管理。上述后端数据与接口保留，需要时可恢复入口。

## 1.3 不做清单（防蔓延）

- 不做检验机构检测功能。
- 不在管理端提供平台凭证配置界面——`REG_*` 只能走云托管环境变量（2.1 凭证态仅在同步看板展示）。
- 不提供批量自动重试入口——`REG_RETRY_AUTO` 保持 false，重报只能逐条人工触发。
- 不做统计报表/绩效/预警配置/审计（随 V2.0 裁剪，接口保留）。
- 2.8 存量提交不做管理页面——`REG_LEGACY_UPLOAD_ENABLED` 默认关，同步看板仅展示开关状态。

# 五、核心流程

## 5.1 管理端主闭环

```
建档（单位/使用单位/人员/电梯；2.2 同步主体ID；2.7 平台回填；1002 互斥预校验；**批量绑定维保人员**）
  → 平台登记（2.3 服务关系：使用单位↔维保单位合同；2.4 人员登记：证书文件→PENDING_SYNC→2.5 回填 platform_id）
  → 电梯贴码（生成二维码 → 现场贴梯 → 小程序扫码签到）
  → 计划调度（排班 → 指派 → **自动派单：每日 09:00 到期扫描 → 按电梯绑定人员派单；首次维保/补单 → 手动"立即派单"**）
  → 工单监控（小程序作业 → 2.6 上报 → 失败进入异常清单）
  → 上报异常闭环（逐条人工重传 → 成功出清单 → 上报日志留痕；**记录预览/PDF 下载**）
  → 档案退出（电梯停用/删除：终止服务关系 → 无在途 → 停用/物理删除）
```

## 5.2 重置密码流程（V2.2 新增，服务小程序"忘记密码"）

```
维保人员点"忘记密码"→ 提示联系管理员
  → 管理端 档案→人员档案→目标人行内"重置密码"
  → 服务端生成 12 位随机密码 → 一次性弹窗展示给操作人
  → 操作人转交本人 → 本人用新密码登录小程序 → 可自助改密（我的→修改密码）
```

> 安全红线：重置密码仅 ADMIN 可用；随机密码仅一次性展示，不落日志；不恢复用户权限管理模块。

## 5.3 电梯档案删除/停用流程（V3.1 新增，用户需求）

```
业务场景：同一使用单位多台电梯，部分电梯未签合同/已丢失维保 → 需从系统移除对应电梯档案。

电梯档案行"删除" → 服务端防护检查：
  ├─ 有在途工单（待接收/作业中）→ 拒绝（提示先完成或转派）    [接口既有 DELETE /elevators/{id} 防护]
  ├─ 无在途工单 + 无历史维保记录/急修单 → 可物理删除（清理误建/未签约电梯，二次确认弹窗）
  └─ 无在途工单 + 有历史维保记录 → 提示改为"停用"（逻辑删除 status=INACTIVE，
       历史记录保留——数据不可变 ≥4 年 TSG 第十条；停用后不派单、小程序不可见）

提示：删除/停用前建议先在"平台登记→服务关系维护"确认该单位 2.3 服务关系已终止（平台侧）。
```

## 5.4 异常与边界

| 场景 | 处理 |
|---|---|
| 上报失败 | 异常清单置顶，红色 FAILED 标签；逐条人工重传，无批量重试 |
| 人员 platform_id 未同步 | 排班时禁止派工并提示原因；人员登记页状态 PENDING_SYNC 高亮，自动 5s/15s/60s 轮询 2.5（最长 5 分钟） |
| 手机号互斥冲突 | 建档/排班拦截，展示 `conflicts[]` 具体冲突角色对 |
| 消防/防爆电梯未配置模板 | 排班拦截（1006）。⚠️ 模板管理页已随 V2.0 裁剪、CUSTOM 后置——**当前该拦截无系统内补救路径**：消防/防爆电梯暂不支持自动派单，如需接入须后置恢复最小模板配置功能，或线下人工安排维保并纸质留痕 |
| 电梯位置待补 | 档案页黄色高亮 + 看板计数；"批量导入经纬度"入口补录 |
| 2.3/2.4 平台返回非 200 | 登记记录落 `reg_upload_log`（action=REGISTER），页面展示失败原因与重试 |
| 2.4 登记后 2.5 匹配不到/证书号重复 | 告警人工处理，不自动取第一条；状态停留 PENDING_SYNC |
| 电梯删除被拒 | 弹窗展示具体拒绝原因（在途工单/历史记录），并给出替代路径（转派/停用） |
| LEADER 越权写操作 | 403 页，写接口门禁拦截 |

## 5.5 派单机制（V3.2 明确，自动为主 + 首次手动）

**原则**：日常维保到期**自动派单**；无首次维保时间/补单/停用恢复的电梯**手动派单**。自动派单的数据前提是**电梯已绑定维保人员**（§6.11 批量绑定）。

```
自动派单（每日 09:00 定时任务 + 触达即时补派）：
  扫描"到期前 24h 内"电梯（上次维保日期 + 类别码间隔：HM≤15d / TM≤90d / SM≤180d / OY≤365d）
  计划时间 = 到期日当天 09:00（同项目同日到期 → 一次性全部派单，scripts/verify-dispatch.js 验收口径）
  → 保养类型按时间自动升级（OY→SM→TM→HM，取最临近周期）
  → 派给电梯绑定的 维保人员1（主）/ 维保人员2（配合）
  → 校验：platform_id 已同步（1004）、手机号互斥（1002）、证件有效期（1007）
  → 生成工单 + 写消息中心
  → 未绑定人员的电梯 → 不进自动派单，看板"待绑定电梯"提示先批量绑定

手动派单（首次维保/补单）：
  电梯档案行"立即派单"（POST /elevators/{id}/dispatch）
  → 跳过到期检查，直接为无首次维保时间的电梯生成首保工单（或补单）
```

# 九、关键设计决策

| # | 决策 | 理由 |
|---|---|---|
| 1 | 手动重报直接复用 `/platform/records/{id}/reupload`（记录 ID） | 避免两套重报入口；幂等红线一致 |
| 2 | 上报日志 `request_digest` 管理端只读展示脱敏版 | 安全红线；明文需求出现时再加独立权限 |
| 3 | 手机号互斥校验（1002）放**服务端**，管理端仅展示 `conflicts[]` | 校验前移至建档期 |
| 4 | 电梯"位置待补"看板/档案高亮 + 批量导入经纬度入口 | docs/01 §3.4.1 降级策略，平台不提供坐标 |
| 5 | 管理端不做平台凭证/重试开关配置界面 | 安全红线 |
| 6 | 重置密码仅 ADMIN、随机密码一次性展示不落日志 | 服务忘记密码最小方案 |
| 7 | 主色 #0052D9 与小程序统一 | docs/03 V2.0 §7.1 |
| 8 | **2.3/2.4 从看板内表单升级为独立管理页**（列表+新建+终止+留痕） | 平台交互核心链路，需建/销/查闭环；docs/04 A.0.2 原"一次性动作不做页面"表述废止 |
| 9 | **电梯删除分物理删除/逻辑停用两级**：无在途+无历史→物理删；有历史→停用（status=INACTIVE） | 数据不可变 ≥4 年（TSG 第十条）要求历史记录保留，删除不可破坏引用；用户需求"清除未签约/失保电梯" |
| 10 | 2.8 存量提交不做页面，同步看板仅展示开关状态 | 临时接口，`REG_LEGACY_UPLOAD_ENABLED` 默认关 |
| 11 | **派单机制：自动派单为主（每日 09:00 到期扫描 + 类型自动升级 + 触达补派），首次维保/补单手动"立即派单"** | docs/01 §3.6 + docs/04 A.8 既有口径明确化；无首次维保时间的电梯无法自动判期，须人工首派 |
| 12 | **批量绑定维保人员是自动派单的数据前提**（`POST /elevators/batch-assign-workers`）；未绑定电梯不进自动派单、看板提示 | 电梯绑定了 人员1/2，自动派单才有派工对象；避免"到期无主" |
| 13 | 维保记录管理端**预览与 PDF 下载内容一致**（复用 A.0.3），入口在工单详情与异常清单 | 一次实现两处复用；预览满足快速核对，PDF 满足归档/留痕 |
