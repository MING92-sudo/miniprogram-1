# 梯维通 LIFT/OPS · 管理端（Web 后台）原型规格 V1.0

> 本文件是 `UI/admin/` 高保真原型的**实现契约与验收契约**。
> 口径来源：`roles-permissions.md`（V1.2，9 角色 / 71 权限码 / 6 数据范围 / 脱敏 / 状态机）与 `routes-and-menus.md`（V1.0，ROLE_TABS / 路由白名单）。
> 现有 `index.html` 的 12 屏为**小程序移动端**原型，本文件**不覆盖**其页面，仅复用其设计 token 与术语。
> 源文档在本期**只读**，不做任何修改；发现冲突仅记录（见 §9）。

## 1. 范围与形态

| 项 | 约定 |
|---|---|
| 端 | 桌面 Web 管理端（后台），路由命名空间 `#/admin/*` 简化为 `#/<view>`（Web 侧独立命名空间，不与小程序 `/pkg-admin/*` 子包混用） |
| 交付形态 | 可点击高保真原型，纯静态多文件，`file://` 双击即用 |
| 外部依赖 | **零**：不引 CDN、不引网络字体、不发网络请求；图标为**内联 SVG sprite**（`icons.svg` 为源文件，同一份内容内联进 `index.html`，因 `file://` 下外部 `<use href="x.svg#id">` 被 CORS 拦截） |
| 分辨率 | 优先 1440×900，兼容 1280；`<1024` 顶部常驻"建议桌面访问"提示条 |
| 本期视图 | 17 个核心视图 + 设计规范视图 + 403/空/加载/失败四态 |
| 二期（不实现） | 配件库存、消息模板、服务评价、监管平台同步明细、大屏调度 |

文件清单：

```
UI/admin-spec.md              本文件（规格）
UI/admin/index.html           入口 + 内联 SVG sprite
UI/admin/assets/admin.css     token 层 + 组件层
UI/admin/assets/mock-data.js  唯一数据源（window.LIFT.mock）
UI/admin/assets/app.js        权限/路由/渲染/交互（window.LIFT.app）
UI/admin/assets/icons.svg     图标源文件（内联进 index.html 的同一份内容）
```

| 维保部经理 | `MAINT_MGR` | 赵启明 | `ALL`（全部维保项目） | 全部维保项目与单据；不进入组织/审计/系统配置（无权限码） |

**导航可见性规则（本原型实现口径）**

1. 视图可见 = 该视图的**页面级权限码**在当前角色的权限矩阵中 ≠ `-`（`Y` 可操作 / `C` 只读或需审批）。
2. `PLATFORM_ADMIN` 例外：对 `plan:view`、`order:view_pool` 文档未列出平台，但依 roles L36「可排查数据」+ §5.2 `ALL` 运维范围，**授予导航可见 + 只读排查**，视图上标注「运维只读」徽标；按钮级权限仍严格按矩阵（平台无 `plan:generate`、无 `order:dispatch`）。该例外记为偏离 **D3**。
3. 直接输入无权限的 hash 路由 → 渲染 **403 视图**，并列出该页所需权限码与允许角色（roles §9 用例 1、4、5、7 的前端体现）。
4. 按钮级：`Y` → 可用；`C` → 置灰 + tooltip 说明（只读/需审批/仅限非管理角色）；`-` → **不渲染**（隐藏）。前端隐藏不作为安全边界（roles L20）。

## 4. 核心对照表（页面 → 路由 → 权限 → 数据范围 → 字段 → 操作 → 单据状态）

字段列中 `(密)` = 按 §6 脱敏规则随角色变化；`操作`列格式 `按钮文案 [权限码] 可用性`。

### ① 登录 · `#/login`

| 项 | 内容 |
|---|---|
| 权限 | 无（未认证）；文档未定义后台账号体系，本期为**已批准推导**（D5）：账号 + 密码 + 角色上下文由"后台"返回 |
| 数据范围 | 登录后由 `me.dataScope` 下发 |
| 字段 | 账号 `(必填,格式)`、密码 `(必填,≥6)` |
| 操作 | 登 录 `—`；演示账号快捷填充 `—` |
| 校验 | 账号空 → "请输入后台账号"；密码 <6 → "密码至少 6 位"；账号非演示集 → "账号不存在或无后台权限" |
| 落地 | 登录成功写入 `LIFT.state.me`，跳 `② 概览工作台` |
